A.S.T.R.A.

Adaptive System for Trajectory, Routing & Advancement

このアプリについて

A.S.T.R.A. は、個人利用を目的として開発しているローカルAIアシスタントです。日程管理機能のために Google Calendar API を利用し、利用者自身のカレンダー予定の参照・作成・更新・削除を行います。

Google データの利用目的

Google Calendar から取得した情報は、A.S.T.R.A. の予定管理機能を提供するために必要な範囲でのみ利用します。広告、販売、マーケティング目的には利用しません。

プライバシー

Google API を通じて取得する情報の取り扱いについては、プライバシーポリシーをご確認ください。
