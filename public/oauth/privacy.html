プライバシーポリシー

A.S.T.R.A. は、個人利用を目的として開発しているローカルAIアシスタントです。本ポリシーでは、Google OAuth および Google Calendar API を通じて扱う情報について説明します。

1. 取得・処理する情報

A.S.T.R.A. は、利用者がGoogle OAuthで許可した範囲内で、Google Calendarの予定情報を取得・作成・更新・削除することがあります。これには、予定の日時、件名、説明、場所、参加者など、対象のカレンダーイベントに含まれる情報が含まれる場合があります。

2. 利用目的

取得したGoogle Calendarの情報は、予定の確認、登録、変更、削除、日程管理など、A.S.T.R.A. の機能を利用者本人に提供するためにのみ使用します。

3. 第三者提供・販売

Google APIから取得した利用者データを第三者へ販売しません。また、広告、広告配信、マーケティング、信用調査その他これらに類する目的には利用しません。法令に基づき開示が必要な場合を除き、利用目的と無関係な第三者への提供は行いません。

4. 認証情報とデータの保管

OAuth認証情報は、A.S.T.R.A. がGoogle APIへアクセスするために利用します。A.S.T.R.A. はローカル環境での利用を前提としており、認証情報およびGoogle Calendarのデータは、機能提供に必要な範囲で利用者の実行環境内で処理・保管します。

5. データの削除とアクセス権の取消し

利用者は、A.S.T.R.A. 側の保存情報を削除するほか、Googleアカウントのセキュリティ設定からA.S.T.R.A. のGoogleアカウントへのアクセス権を取り消すことができます。

6. Google API Services User Data Policy

A.S.T.R.A. によるGoogle APIから取得した情報の利用は、Google API Services User Data Policy（Limited Use要件を含む）に従うことを目的としています。

7. ポリシーの変更

A.S.T.R.A. の機能またはGoogle APIの利用方法に変更があった場合、本ポリシーを更新することがあります。
